# Task 3: Go API Implementation

A read-only JSON REST API for the Rocket Elevators Ontario fleet dataset, written in Go using the standard library (`net/http`, Go 1.22 ServeMux).

## Running the server

```bash
# From the platform/api/ directory
go run .

# Server listens on :8081 by default
# Override port
PORT=9000 go run .
go run . -port 9000

# Override data directory (default: ../../data relative to working dir)
DATA_DIR=/path/to/data go run .
```

The server loads all CSV data into memory at startup and logs how many records were found. If `data/predictions.csv` does not yet exist, the server starts normally — `GET /api/elevators/{id}/risk` returns `503` until the file is generated by Task 6.

## Endpoints

All responses are `Content-Type: application/json; charset=utf-8`. All errors return a JSON body `{"error":"CODE","message":"..."}`.

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/api/elevators` | Paginated fleet list. Query params: `page` (default 1), `limit` (default 100, max 500), `status` (filter by `LICENSESTATUS`). |
| `GET` | `/api/elevators/{id}` | Full detail for one elevator — license, ownership, device classification, alteration summary, latest inspection. |
| `GET` | `/api/elevators/{id}/inspections` | Complete inspection history, sorted most-recent-first, with compliance orders nested inline. |
| `GET` | `/api/elevators/{id}/risk` | ML-predicted next inspection outcome. Returns `503 PREDICTIONS_UNAVAILABLE` until Task 6 generates `data/predictions.csv`. |

### Status codes

| Code | Meaning |
|------|---------|
| `200` | Success |
| `400` | `INVALID_PARAMETER` — malformed `id` or out-of-range query param |
| `404` | `ELEVATOR_NOT_FOUND` — unknown elevator id |
| `503` | `PREDICTIONS_UNAVAILABLE` — `predictions.csv` not yet generated |

## Data sources

| File | Used by |
|------|---------|
| `data/merged_elevator_data.csv` | `/api/elevators`, `/api/elevators/{id}` |
| `data/inspection.csv` | `/api/elevators/{id}/inspections` |
| `data/order.csv` | `/api/elevators/{id}/inspections` (nested orders), `/api/elevators/{id}/risk` (open-order count + mean risk score) |
| `data/predictions.csv` | `/api/elevators/{id}/risk` (forward dependency — generated in Task 6) |
