## Use cases
2. What do you use them for? (e.g., writing, coding, research, brainstorming, debugging, learning). Be specific: "I paste error messages into ChatGPT" is more useful than "I use it for coding". Use cases include at least one concrete example of a real interaction (not hypothetical)

A. Claude Code
-I use Claude Code for Application Development which is more complex and requires thorough implementation of features,components, and debugging.

Example: In the Codeboxx Training program, while building the Rocket Delivery app, I created spec docs and use Claude for implementation of the entire app because it was quicker, refined and reliable.  


B. ChatGPT
-I use ChatGPT for research, learning, wireframing, and image creation/manipulation.


While working on my portfolio  I ask ChatGPT what information is typically included in a Porftolio for a Full Stack Mern Developer.  ChatGPT provided suggestions and create a wireframe per my request.


C. Copilot
-I use Copilot for simple task that aren't code heavy, like file creation/editing for text/md files. Simpler coding tasks using scripting  languages   vs. object oriented programming.


The most recent example was getting this project setp up and creating the .md files. Given that Claude Code uses  tokens, I try to use Copilot for less complex tasks and reserve the heavy lifting for Claude.


D. Gemini
-I use Gemini, for image creation/editing.

Gemini is my go to for image composition.  A site that I am working on needed a specific background with a cutout image of the client on top.  I provided the description of the environment which the subject needed to be in and it created a blended  composition that looked  professional.




## Typical interaction
3. Describe what a typical session looks like. How do you start? How long does it last? How do you use the output?

Typical sessions usually invole a thought out prompt with expedient task execution.  For large projects create spec docs and request for AI to use them as a reference while implementing the tasks. I ask for an explanation before the task it executed to ensure that my request is understood and so that I am able to gain a perspective of how the solution works. I test/review  the  solution immediately and  make corrections immediately.

## What works 
4. What do you find effective about your current approach?

Currently my approach is systematic, organized, and efficient.  I am able to  work by breaking requirments into small tasks and build.  What took me weeks, now takes me days.



## What doesn't
5. What frustrates you or feels inefficient?

The Token usage in Claude Code.  There have been times that I have gotten into a groove and the project is going well, then I get the message that I have ran out of tokens.  There is no way of knowing how many tokens are being used prior to a prompt request.

Other times I find it frustrating when I am debugging code and the  error keeps occurring.  Claude sometimes identifies it's own  mistakes in programming.

Confidence level: On a scale of 1-5, how confident are you that AI-generated outputs are correct before you use them? What do you do to verify?

I would say about a 3.7 out of 5.  Claude sometimes does things that I didn't request, or it misinterpretted my prompt and I have to  correct it.
